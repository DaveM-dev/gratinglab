# gratinglab

This is a Python package that solves two inverse problems:
Recovering a grating's period, duty cycle and depth from its diffraction signature
And phase retrieval. 

These are done using the simulated data, from simulating scalar diffraction from surface gratings, with an FFT propagator.


Scope: This is a scalar and thin element model of surface gratings. This model holds when the features are much bigger than the wavelength and the relief is shallow. RCWA, a rigorous electromagnetic treatment, will be conducted at a later stage.

Backend: The physics code is written against an array namespace, `xp`, so the same code runs on NumPy or PyTorch. PyTorch supplies automatic gradients.

Data: All data is synthetic and generated by the package's own forward model.

Status: This is in early development. The future steps are planned as follows:

1. A forward model for 1D and 2D gratings, tested against the grating equation, energy conservation and analytic results.
2. Fast, batched, differentiable evaluation.
3. A deliberately naive least-squares solver for period, duty cycle and depth, with its failure region mapped.
4. A Gerchberg–Saxton phase-retrieval baseline.
